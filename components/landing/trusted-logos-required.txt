Target section/component:
- components/landing/social-proof-strip.tsx

Where logos live:

Brand logo files (self-hosted SVGs):
1) Microsoft   -> public/landing/logos/microsoft.svg
2) Google      -> public/landing/logos/google.svg

Display constraints in this UI:
- Height: ~32px visual height
- Width: 70px to 120px per logo (see LOGOS array widths)
- Keep similar optical weight so marquee spacing stays balanced

To swap a brand:
- Replace the SVG at the path above (same filename), OR
- Update the LOGOS array in components/landing/social-proof-strip.tsx

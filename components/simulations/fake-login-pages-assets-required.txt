Fake login pages — images, logos, and names checklist
======================================================

Purpose
-------
Asset list for phishing-simulation landing pages shown at:
  /login/[campaignId]/[employeeToken]

Code references
---------------
- Variants:     components/simulations/variants/*.tsx
- Logos (SVG):  components/simulations/logos/index.tsx  (inline today — no raster files)
- Registry:     components/simulations/registry.ts
- Page titles:  components/simulations/variant-meta.ts
- Templates:    lib/campaign-templates.ts (landingPageType per campaign)

Suggested storage (if you add raster/SVG files)
-----------------------------------------------
  public/simulations/logos/     — brand marks
  public/simulations/favicons/  — browser tab icons (16×16, 32×32)
  public/simulations/ui/        — optional hero/illustration backgrounds
  public/simulations/org/       — per-tenant logos (uploaded at onboarding; see org.logoUrl)

Format guidance
---------------
- Logos: SVG preferred (crisp at any size); PNG with transparency as fallback
- Favicons: ICO or PNG 32×32
- Keep file sizes small; training pages load on mobile
- Use only marks you are licensed to use for internal security training

Note: Today all brand marks are hand-drawn inline SVG components. This file lists what
you would need if replacing them with production-quality assets.
